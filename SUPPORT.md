# Support

For bugs, feature requests, and usage questions, use the [JS Runner issue tracker](https://github.com/projectGloria/jsRunner/issues).

## Before reporting a problem

1. Check the [README troubleshooting section](README.md#troubleshooting).
2. Confirm your Node.js executable is version 20.19 or newer. If you set `jsRunner.nodePath`, check that executable rather than only the `node` on your terminal's `PATH`.
3. Try a minimal, complete JavaScript selection in a trusted workspace.

## What to include

- JS Runner version and VS Code version.
- Operating system and Node.js version.
- A small example file, with the exact selection marked.
- Any local imported files needed to reproduce the behavior.
- Expected result and actual output, copied from the JS Runner panel.
- Relevant `jsRunner` settings and whether the source was saved or unsaved.

Remove tokens, passwords, private data, and sensitive file paths before sharing code or output. If your report concerns automatic context loading, include the declarations around the selection as well as the selected snippet.

## Feature requests

Describe the task you are trying to complete, how you currently handle it, and an example of the behavior you would like to see.
